# タスク完了時のチェックリスト

## 必須確認事項

### 1. コードスタイル
- [ ] セミコロンが全ての文末にあるか
- [ ] ダブルクォートを使用しているか
- [ ] ESLintエラーがないか

### 2. ビルド確認
```bash
pnpm build
```
- [ ] ビルドが成功するか
- [ ] `dist/index.html`が生成されるか

### 3. 動作確認
```bash
pnpm dev
```
- [ ] 開発サーバーが起動するか
- [ ] 主要機能が動作するか
  - パノラマ画像/動画の読み込み
  - テキストラベルの追加・編集
  - 矢印の追加・編集
  - 画像エクスポート

### 4. Git
- [ ] 不要なファイルがコミットに含まれていないか
- [ ] コミットメッセージが適切か

## 注意事項
- Vite設定で`minify: false`のためビルド成果物は非圧縮
- 単一HTMLファイル出力のため、外部リソース参照に注意
- Three.jsのリソース解放を忘れずに（メモリリーク防止）
