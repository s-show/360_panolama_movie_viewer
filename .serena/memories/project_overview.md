# 360度パノラマビューワー - プロジェクト概要

## 目的
360度パノラマ画像/動画のビューワーアプリケーション。テキストラベルと矢印のアノテーション機能を備え、アノテーション付きのエクイレクタングラー画像としてエクスポート可能。UIは日本語。

## 技術スタック
- **Three.js** (v0.176.0) - 3Dレンダリング、パノラマ投影
- **Vite** (v6.3.5) - ビルドツール、開発サーバー
- **Sass** (sass-embedded v1.89.1) - スタイリング
- **vite-plugin-singlefile** (v2.2.0) - 単一HTMLファイル出力
- **Vanilla JavaScript** (ES modules) - フレームワークなし

## パッケージマネージャー
pnpm（推奨）またはnpm

## 主要機能
1. **パノラマ表示**: 反転球体ジオメトリにテクスチャを投影
2. **メディア対応**: 静止画・動画の両方をサポート（マジックバイトでファイルタイプ判定）
3. **アノテーション**: テキストラベル（スプライト）と矢印（シリンダー+コーン）
4. **インタラクション**: OrbitControlsでカメラ操作、TransformControlsでアノテーション編集
5. **エクスポート**: CubeCameraとシェーダーでエクイレクタングラー画像生成

## ビルド出力
本番ビルドではJS/CSSがインライン化された単一HTMLファイルを出力（`dist/index.html`）。配布が容易。
